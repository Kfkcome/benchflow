## Minimum Merge Gate

Required before PR merge:

```bash
uv run ruff check .
uv run ty check src/
uv lock --check
git diff --check
uv run python - <<'PY'
from pathlib import Path
import pytest
import benchflow._agent_env as agent_env
agent_env._DEFAULT_DOTENV_PATH = Path('/tmp/benchflow-no-dotenv-for-tests')
raise SystemExit(pytest.main(['tests/', '-q']))
PY
uv run python scripts/export_docs_to_website.py --check --website-root ../www.benchflow.ai
```

## Minimum Tag Gate

Required before tagging `v0.4.0`:

- Minimum merge gate passes.
- Website build passes with Node `v24.13.1` or compatible.
- At least one ACP live smoke and one acpx live smoke have fresh result
  artifacts, or the only live blockers are credential/provider availability.
- `tests/integration/run.sh` has been run when Daytona and provider credentials
  are available.
